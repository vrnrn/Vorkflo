# Public desktop release acceptance

A release is ready only when the following evidence is collected for its source
commit and packaged artifacts.

| Requirement                                                                    | Verification                                                                 |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Portable source contains no personal bindings or private workflows             | Public-source audit plus manual source and image review                      |
| Contracts, validation, scheduling, and runtime behavior remain correct         | `npm run verify`                                                             |
| All workspaces compile                                                         | `npm run build`                                                              |
| Installed app executes and handles cancellation, failure, and history recovery | `node scripts/run-electron-smoke.mjs --packaged`                             |
| Canvas stays usable for 51 nodes and sustained dragging                        | `node scripts/run-electron-smoke.mjs --packaged --performance`               |
| Helpers work without a checkout                                                | Packaged helper paths, controlled helper invocation, and bundle verification |
| DMG and ZIP contain matching application payloads                              | `npm run verify:mac:release`                                                 |
| Downloads match the published checksum manifest                                | SHA-256 verification of the release assets                                   |
| GitHub performs the build and publishes tested assets                          | Successful Release workflow for the published commit                         |

Acceptance uses synthetic workflows and isolated application data. No personal
CLI configuration, credentials, user workflow, or account service is required
for automated execution tests. Real third-party Agent and MCP behavior remains
owned by the installed external tools and their local configuration.

Before making a repository public, review all reachable Git history and author
metadata, not just its working tree. Historical screenshots require pixel
review. Deleting private content in a later commit does not remove it from
earlier commits or hosting caches.
