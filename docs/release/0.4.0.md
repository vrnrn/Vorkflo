Vorkflo brings local command-line tools onto a visual workflow canvas. Build a
DAG, review its authority, run independent branches, and inspect the resulting
text, JSON, and file artifacts.

This release includes process blocks; Codex, Cline, and Antigravity Agent
runtimes; explicit Git worktrees; generic bounded Computer Use; and persistent
local run history. Runtime helpers are included in the downloaded application.

The editor has dedicated modules for process configuration and run inspection.
Incomplete Computer Use edits show actionable validation messages. The public
source includes synthetic examples, contributor guidance, and repeatable GitHub
builds.

Download the **DMG** for drag-and-drop installation or the **ZIP** for a
portable application bundle. Both support **Apple silicon Macs on macOS 12 or
later**. Use `SHA256SUMS.txt` to verify your download.

**Unsigned release:** these downloads are not Developer ID signed or notarized.
macOS may require a per-application security override. Installation instructions
are in `docs/release/MACOS.md` in the repository.

Workflows execute trusted local code with your operating-system permissions.
Agent and browser tasks require separately installed, authenticated tools.
