A FEW GOOD QUESTIONS

          
Before you
go with the flow.

          Read the documentation
        

        

          

            
              Is Vorkflo free?
            
            

              Yes. Vorkflo is free and open source under the MIT license. You bring your own tools;
              any paid AI services or accounts those tools use are separate.
            

          

          

            
              What do I need to get started?
            
            

              The desktop download supports Apple silicon Macs running macOS 12 or later. Install
              the command-line tools you want to use. Agent blocks also need the selected CLI’s
              authentication.
              Follow the installation guide.
            

          

          

            
              Why does macOS ask before opening it?
            
            

              The current release is unsigned and has not been notarized by Apple. Verify the
              download against the release checksums, then follow the installation guide’s steps if
              you decide to trust it.
              Get the checksums.
            

          

          

            
              Do my workflows stay on my machine?
            
            

              Vorkflo stores workflows, drafts, and run history locally. The tools you run can still
              access the network or their own services. Processes run with your operating-system
              permissions; review workflows as carefully as scripts.
              Read the security model.
            

          

          

            
              Can I use Windows, Linux, or an Intel Mac?
            
            

              There are no supported packaged releases for those platforms yet. Developers can
              explore the source and its setup instructions on GitHub.
